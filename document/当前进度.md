## ⚠️ 让后台真正跑起来，需要你做（约 5 分钟）
后台要连数据库才能用，而这需要你的账号（我无法代建）。步骤：

1. **建一个免费 Postgres**：注册 [Neon](https://neon.tech) 或 Supabase，新建数据库，复制连接串（Neon 记得带 `?sslmode=require`）。
2. 填入 `.env.local`：
```bash
DATABASE_URI=postgres://…你的连接串…
PAYLOAD_SECRET=一段够长的随机串
```
3. 启动并打开后台：
```bash
npm run dev
```
浏览器访问 `http://localhost:3000/admin` → Payload 会自动建表并让你**创建第一个管理员** → 登录后即可**无代码增删商品、写博客、处理买取**。

4. （启用支付时）在 `.env.local` 填 `STRIPE_SECRET_KEY` 等测试密钥；本地测 Webhook 用 `stripe listen --forward-to localhost:3000/api/stripe/webhook`。
5. **上线 Vercel**：把这些环境变量配到 Vercel，再加一个 `BLOB_READ_WRITE_TOKEN`（Vercel Blob 存图），Stripe 后台把 Webhook 指向 `https://你的域名/api/stripe/webhook`。
